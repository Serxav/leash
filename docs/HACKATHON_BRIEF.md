# Hackathon brief

PayPal AI Hackathon on Devpost. Official rules: https://paypalaihackathon.devpost.com/rules.
The official rules always win over this file.

## How judging works

- **Stage one, pass/fail:** the project fits the theme and uses the required PayPal
  APIs/SDKs.
- **Stage two:** five criteria with the same weight. Ties are broken by the first one.

| Criterion | Where Leash answers it |
|---|---|
| Technological implementation | Vault, Orders v2, Payments v2 refunds and the Agent Toolkit, all in sandbox; an AI agent that can only propose; a tested policy engine ([ARCHITECTURE.md](ARCHITECTURE.md)) |
| Design | A complete product: rules, chat with Rex, approval cards, inbox, history, permissions, on desktop and phone |
| Potential impact | Small teams can let an agent shop without handing it their wallet; the user approves, as PSD2 expects |
| Innovation | Plain-language rules turned into exact rules, and prompt injection from shop text caught by code |
| Presentation | [DEMO_SCRIPT.md](DEMO_SCRIPT.md): the full loop in under 3 minutes |

## What the rules ask for

- Built from scratch during the submission period (repository created Oct 15, 2026).
- PayPal at the centre, in sandbox. README and description name the PayPal APIs, the AI
  models and where each part lives.
- A web app for desktop and mobile that installs, runs and works as the video shows.
- Free test access until the end of judging: the live demo and the sandbox login.
- Public repository with an open source licence (MIT).
- Video under 3 minutes, public on YouTube, no third-party trademarks or copyrighted music.
- Everything in English.
- Sponsor tools used under their terms and named: Channel3, Render.
